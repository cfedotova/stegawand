how it works

short theory + interactive visualization of the bit codes

1. spread-spectrum idea (CDMA)

The system doesn’t “put bits into individual pixels” like LSB does. Instead, each of the {{ msg_bits }} message bits is assigned a unique random ±1 spatial code of size {{ image_size }} × {{ image_size }} that covers the whole image. One bit ⇒ one code spanning the entire picture.

Encoding the message into one spatial pattern:

p(x, y) = (1/√N) · Σᵢ (2bᵢ − 1) · cᵢ(x, y)

where bᵢ ∈ {0,1} is the i-th bit, (2bᵢ−1) ∈ {−1,+1} is its BPSK sign, and cᵢ is the fixed random ±1 code for that bit.

2. decoding — matched filter

The decoder doesn’t “guess” bits — it correlates the recovered pattern against every code. The logit for bit i: 

ℓᵢ = (1/√(HW)) · Σ(x,y) p̂(x, y) · cᵢ(x, y)

The sign of ℓᵢ gives the bit. SNR per bit grows by a factor of √(HW) = 256 thanks to summing over 65 536 pixels — that’s why a tiny residual (5 % of pixel range) still gives ≈ 100 % decoding accuracy.

4. loss function and warm-up schedule

Training loss is a combination of message BCE and image L1:

L = w_msg · BCE(ℓ̂, b) + w_img(t) · ‖S − C‖₁

w_msg = 5.0,  w_img (target) = 0.3

w_img(t) = {
   0,                                  if t < 300
   w_img · (t − 300) / 400,            if 300 ≤ t < 700
   w_img,                              if t ≥ 700
}

For the first 300 steps the encoder is rewarded only for being decodable (image-loss = 0). Otherwise it would collapse to a zero residual — image-loss would go to zero but bit-acc would stay at chance.
